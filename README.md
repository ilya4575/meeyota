# meeyota

Персональная страница — BIO.

## Стек

Чистый HTML/CSS/JS без сборки и зависимостей. Внешне подключён только Font Awesome (иконки).

## Что внутри

- **Интро-анимация** при заходе: снежинки слетаются в точку → вспышка → расходящееся кольцо → плавный кроссфейд на страницу. Всё на `transform`/`opacity`, чтобы не было просадок FPS. Учитывается `prefers-reduced-motion`, есть автоскрытие на случай сбоя скрипта.
- **Каскадное появление** интерфейса: аватарка, ник, теги, био, кнопка плеера и соцсети выезжают по очереди.
- **Плеер** в стиле iOS: раскрывается прямо под кнопкой с пружинной анимацией, мини-эквалайзер, seek и громкость с белой заливкой.
- **Живой фон**: зимний лес с дрейфом, падающий снег на `<canvas>` (рисуется батчами, на паузе во время интро).
- **Ping-индикатор**: честный RTT через запрос к `ping.txt`, берётся минимум из нескольких проб.
- **`intro-examples.html`** — витрина вариантов интро (5 штук + гибрид), с зацикливанием для сравнения.

## Локальный запуск

Любой статический сервер из папки проекта, например:

```bash
python3 -m http.server 8080
```

