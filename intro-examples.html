Как это будет встроено в сайт

Интро — отдельный слой поверх страницы со position: fixed. Он играет один раз (или при каждом заходе), затем снимается, чтобы не мешать плееру и снегу. Запоминание показа — через sessionStorage.

<div id="intro" class="intro intro--iris"></div>
<script>
  const intro = document.getElementById('intro');
  document.documentElement.classList.add('intro-lock');
  window.addEventListener('load', () => {
    setTimeout(() => {
      intro.classList.add('done');
      document.documentElement.classList.remove('intro-lock');
      setTimeout(() => intro.remove(), 800);
    }, 1500);   // длительность анимации
  });
</script>

Плюс к этому — блокировка скролла на время интро и prefers-reduced-motion, чтобы при отключённой анимации сайт открывался сразу.
